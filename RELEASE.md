# Release 0.1.0

This GitHub tag is the native Codex distribution: `codex plugin marketplace add AceDataCloud/SunoCodex --ref v0.1.0` followed by `codex plugin add suno@acedatacloud-suno --json`. No npm/PyPI package or separate server deployment is required.

The manifest version is 0.1.0. The tag pins this source and `SHA256SUMS` on the GitHub Release covers the attached tar archive. Check the publisher Ace Data Cloud.

Official catalog candidate: https://github.com/openai/plugins/pull/397. A released third-party marketplace is not an official listing. Paid media results and billing were not tested for this release; see README for same-ID task polling.
