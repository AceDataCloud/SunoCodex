# Privacy and data flow

This plugin is provided by Ace Data Cloud. It sends the selected Suno tool request and the service API credential to `https://suno.mcp.acedata.cloud/mcp`, which uses Ace's existing API. It adds no analytics collector. Website CTA links carry four campaign tags; they are not a payment ledger.

The credential resolves from `ACEDATACLOUD_API_TOKEN`; no real key is packaged. Do not submit secrets in prompts. Media operations may incur charges and may process content through the selected service. Follow the platform's current service terms and account controls; installing this package does not accept any publisher or service contract on behalf of the user.

Only submit authorized content. Contact dev@acedata.cloud with task/trace IDs, never credentials.
